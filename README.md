Built an basic backprop engine using numpy and micrograd by andrej karpathy 
the main purpose was to demonstrate step by step process of making a backprop engine which is clearly demonstrated in the jupyter notebook
used graphviz to visualize the network and backprop but graphs for neural nets with even 3 layers and 4 neuron each is very complex and is not suitable to understand the architecture of the model
the jupyter notebook is self explanatory and can be used for teaching purposes (my motivation to make it was to learn and store it for future reference)


Major concepts :
                1. derivative & implementation of chain rule in neural network training
                
                2. visulization of NN boiled down to being large and complex interconnected equations in layerwise architecture

                3. concept of forward and backward pass
                4. illustration of why gradients should be initialized to zero after evry backward pass
